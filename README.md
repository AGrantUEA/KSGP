# KSGP
Scripts used to generate KSGP database from sources

The scripts are not entirely machine independent, but are provided to document the processes used to generate the GTDB+ and KSGP databases. KSGP_v3.1 is a SLURM batch job that generates KSGP with three different sets of taxonomic annotations (LCA, Sintax and KSGP+) and GTDB+. The script includes flags that can be set if only parts of the database need to be updated/regenerated.
